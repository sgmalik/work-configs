File generated by Skill is not getting recognised as AI generated file in SCE UI and also Audit is not showing this details

Issue Description: Files generated or modified by an AI skill are not recognized as AI-generated files in the CDR-SCE UI. Additionally, the Audit history does not capture or display any AI generation details for these files.

Steps to Reproduce:

1. Log in to the CDR-SCE application.
2. Navigate to a workspace and execute an AI skill that generates or modifies a file.
3. Wait for the skill execution to complete successfully.
4. Locate the generated/modified file in the CDR-SCE UI.
5. Verify whether the file is identified as AI-generated.
6. Open the Audit history for the file and review the recorded audit details.

Actual Result:

* The generated/modified file is not identified as an AI-generated file in the CDR-SCE UI.
* The Audit history does not display any information indicating that the file was created or modified by an AI skill.

Expected Result:

* Files generated or modified by AI skills should be clearly identified as AI-generated in the CDR-SCE UI.
* The Audit history should capture and display the AI-related metadata, including the skill/agent responsible for generating or modifying the file, along with the relevant execution details.
