Switching to a Skill/Agent is not working while a workflow is in the Executing state in the Interactive Chat window.

Issue Description

When a workflow is in the Executing state in the Interactive Chat window, attempting to switch to another Skill or Agent does not work. The switch action is not performed, preventing the user from changing the active Skill/Agent during workflow execution.

Steps to Reproduce
1. The user is logged into CDR-SCE and initiates one workflow execution
2. An Interactive Chat session is open.
3. A workflow has been started and is currently in the Executing state.
4. Wait until the workflow status changes to Executing.
5. Attempt to switch to another Skill/Agent using the available switch option or /switch command.
Observe the behavior.
6. type /confirm queue(to start skill execution once the current execution is completed) or /confirm cancel(Cancel the current execution.

Actual Result
The Skill/Agent switch does not occur while the workflow is in the Executing state. The current Skill/Agent remains active, and the requested switch is not getting executed.

Expected Result
The user should be able to switch to another Skill/Agent during workflow execution, or the application should display an appropriate message if switching is intentionally restricted during execution.
