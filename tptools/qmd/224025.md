The session timeout popup is displayed even when a Skill or Workflow is actively running in the Interactive Chat window.

Issue Description
The session timeout popup is displayed even when a Skill or Workflow is actively running in the Interactive Chat window. Since an execution is in progress, the user session should remain active and should not trigger a session timeout.

Steps to Reproduce
1. Log in to CDR-SCE application.
2. Start executing a Skill or Workflow.
3. Allow the execution to continue for longer than the configured session timeout period.
4. Observe the application behavior.

Actual Result
A session timeout popup is displayed while the Skill/Workflow is still running, interrupting the ongoing execution.

Expected Result
The session should remain active while a Skill or Workflow is executing. The session timeout popup should not be displayed until the execution has completed or the user has been genuinely inactive after execution ends.
