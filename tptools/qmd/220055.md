Issue Description: The Compare Cached Tokens (First Run vs. Second Run) details are not available under the Executions tab.

Testing Location:
https://scaf-syc16-staging.sycamoreinformatics.com/scaf/executions

Steps to Reproduce:

1. Execute the same Agent/Skill twice using the same inputs so that token caching is applicable.
2. Wait for both executions to complete successfully.
3. Log in to the S-CAF application.
4. Navigate to Executions → Agent Executions.
5. Open the execution details for both the first and second runs.
6. Look for the Compare Cached Tokens (First Run vs. Second Run) information.

Actual Result:
The Compare Cached Tokens (First Run vs. Second Run) details are not available under the Executions tab.

Expected Result:
The Executions tab should display the Compare Cached Tokens (First Run vs. Second Run) information, allowing users to compare cached token usage between the two executions.
