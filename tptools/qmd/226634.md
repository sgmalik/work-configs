Updated settings page values, doesn't reflect in Audit log table description column.

Issue description : Updated settings page values, doesn't reflect in Audit log table description column.

Steps to reproduce :
-
Navigate to Settings page in S-CAF.
-
Update a settings value.
-
For example , under Runtime and Budget tab  , update the monthly token budget value to 10000 and save the settings.
-
Navigate to audit log and look for settings.update audit entry

Expected result : The description cell in the audit row , should show, what value did user updated in the settings page.

Actual result: The audit log row description only shows the updated settings type, not the value that changed by the user.
