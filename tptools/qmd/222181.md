Skill version comparison report - Synchronized scroll should be implemented

Description : On the comparison report (used when comparing two skill versions or before/after states), scrolling one panel/section does not synchronize with the corresponding panel/section. Each side scrolls independently. This makes it difficult to visually align and compare corresponding content between the two versions being compared, especially for longer documents/outputs.

Test Environment: https://scaf-syc16-staging.sycamoreinformatics.com/scaf
Test Data : https://scaf-syc16-staging.sycamoreinformatics.com/scaf/agent/skills/333

Steps to reproduce :
1. Login to the S-CAF Application.
2. Navigate to the skill authoring page for an existing agent, having multiple versions.
3. Click Versions. Select two versions to compare. Click Compare.

4.Scroll down in one panel (e.g., "Before")

5.Observe the other panel (e.g., "After")

Expected result : Scrolling in one panel should synchronize the scroll position in the corresponding panel, so both sides stay visually aligned - a common pattern in diff/comparison tools

Actual result : Each panel scrolls independently, requiring the user to manually scroll and re-align both sides to compare corresponding sections, adding friction and increasing the chance of misaligned comparisons.
