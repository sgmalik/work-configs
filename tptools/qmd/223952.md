/confirm cancel cancels the current workflow step instead of the entire workflow execution

Issue Description

When a user executes the /confirm cancel command during workflow execution, only the currently executing workflow step is cancelled. The overall workflow execution continues instead of being terminated, which is not the expected behavior.

Steps to Reproduce
1. The user is logged into CDR-SCE and initiates one workflow execution
2. An Interactive Chat session is open.
3. A workflow has been started and is currently in the Executing state.
4. Wait until the workflow status changes to Executing.
5. Attempt to switch to another Skill/Agent using the available switch option or /switch command.
Observe the behavior.
6. type /confirm cancel(Cancel the current execution).

Actual Result
Only the current workflow step is canceled, while the remaining workflow continues to execute.

Expected Result
Executing the /confirm cancel command should cancel the entire workflow execution, and the workflow status should change to Canceled (or the appropriate terminal state).
