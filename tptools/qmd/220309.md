Eval quality score and pass rate fluctuate significantly on heading text modification

Description : Eval quality score and pass rate show a large fluctuation (32% → 0%) after renaming "## Examples" heading to "## Examples - edited"

Test Environment: https://scaf-syc16-staging.sycamoreinformatics.com/scaf
Test Data : https://scaf-syc16-staging.sycamoreinformatics.com/scaf/agent/skills/630

Steps to reproduce :
-
Login to the S-CAF Application.
-
Navigate to an existing skill with a recorded eval quality score and pass rate.
-
Rename the "## Examples" heading to "## Examples - edited". No other content is changed.
-
Save and re-run the eval.
-
Compare the new quality score/pass rate to the original.
-
Repeat with multiple similar edits and/or repeated runs.

Expected result :
-
A heading label change alone (with no change to actual example content or instructions) should not meaningfully affect quality score or pass rate.
-
Repeated eval runs on an unchanged skill version should return consistent scores.

Actual result : Quality score and pass rate vary significantly after heading text modification.
