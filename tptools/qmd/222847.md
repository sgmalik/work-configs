When a user exits a skill while it is still executing, multiple temporary files are left behind instead of being cleaned up.

Issue Description:
When a user exits a skill while it is still executing, multiple temporary files are left behind instead of being cleaned up. These temporary files accumulate and may consume unnecessary disk space.

Steps to Reproduce:
1. Launch the application.
2. Start executing any skill.
3. While the skill is still running, issue the Exit command.
4. Observe the temporary files created in the application's temporary directory.

*8Expected Result:
The running skill should terminate gracefully.
All temporary files created during the skill execution should be cleaned up automatically.
No orphaned temporary files should remain after the application exits.

Actual Result:
The application exits the running skill, but multiple temporary files remain in the temporary directory.
These files are not deleted automatically and continue to accumulate after repeated executions.
