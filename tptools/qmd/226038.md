AI updates to existing workspace files is missing the Audit entry in the CDR-SCE audit log

Description:

When AI creates a file in a workspace, the CDR-SCE audit log correctly records the action. However, when AI updates an existing file on behalf of a user, no audit entry is created.

Steps to reproduce:

1. Open a workspace containing a failed SAS program and its log file.
2. Ask AI to run the Analyze SAS Log skill on the failed program’s log file.
3. Allow AI to analyze the error and update the existing SAS program.
4. Confirm that the updated program displays the AI Generated flag in the UI.
5. Open or refresh the CDR-SCE audit log.
6. Search for an audit entry corresponding to the SAS program update.

Actual result:

The SAS program is updated and displays the AI Generated flag, but no audit entry is created for the update.

Expected result:

The CDR-SCE audit log should record the update and attribute it to the user on whose behalf AI performed the action, just as it does when the user updates the file manually.

The audit entry does not need an “AI-generated” label because the AI Generated status is already displayed separately.
