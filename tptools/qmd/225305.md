AI Review Model details are not captured during Skill/Agent/Workflow execution or in AI LLM Calls Audit Logs when it differs from the AI Generator Model.

### Issue Description

When the AI Generator Model and AI Review Model are configured as different models, there is no visibility into which AI Review Model is actually used during Skill/Agent/Workflow execution. The AI Review Model is captured in the Audit Logs only when it is changed under Settings, but the model information is not shown in the execution details or in the AI LLM Calls Audit Logs.

### Steps to Reproduce

1. Log in to the CDR-SCE application.
2. Navigate to Settings and configure different models for:

* AI Generator Model
* AI Review Model
3. Save the configuration.
4. Execute any Skill, Agent, or Workflow that triggers an AI review.
5. Verify the execution details.
6. Navigate to Audit Logs and review the corresponding AI LLM Calls entries.
7. Check whether the AI Review Model used for the execution is displayed.

### Actual Result

* The AI Review Model is not displayed in the Skill/Agent/Workflow execution details.
* The AI Review Model is also not shown in the AI LLM Calls Audit Logs.
* The model information is captured in the Audit Logs only when the AI Review Model is explicitly changed under Settings.
* As a result, there is no reliable way to determine which AI Review Model was used for a specific execution.

### Expected Result

* The AI Review Model used for each execution should be clearly captured and displayed.
* The model information should be available in the Skill/Agent/Workflow execution details and AI LLM Calls Audit Logs.
* The audit information should identify the exact AI Review Model used for each AI review call, regardless of whether the model was recently changed under Settings.
